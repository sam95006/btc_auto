# NEXUS Participant Consent and Data Minimization V1

Not final legal advice. Region-specific legal review required before launch.

## Do not request

- Exchange withdrawal permissions
- Trading API write access
- Wallet seed phrases / private keys
- Account passwords
- Full identity documents unless later legally required

## Prefer

- Manual portfolio entry
- Redacted screenshots
- Percentage allocations
- Read-only information only

## Must disclose / define

- Participant consent scope
- Data retention period
- Export rights
- Deletion / study withdrawal
- Confidentiality
- AI data-use disclosure
- Cross-border data warning
- Legal-review requirement

## Product boundary reminder

Public Concierge is Decision Support / Research / Risk Awareness / User-controlled Record. No custody, no automatic orders, no guaranteed returns.
