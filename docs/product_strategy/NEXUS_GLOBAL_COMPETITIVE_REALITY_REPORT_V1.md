# NEXUS Global Competitive Reality Report V1

## Competitor categories

1. **Market data terminals** — price, order book, derivatives metrics, charts
2. **News and social aggregators** — headlines, sentiment, influencer feeds
3. **Generic AI chat wrappers** — ask-anything over market snippets
4. **Trading journals / PnL trackers** — post-trade logging without thesis integrity
5. **Alert bots** — price and funding alerts without Decision Objects
6. **Copy-trading / signal marketplaces** — sell signals or mirror trades
7. **Research desks / paid newsletters** — human narrative, weak structured Outcome Review
8. **Portfolio trackers / tax tools** — holdings, cost basis, compliance adjacent

## Capabilities that already exist

- Live prices, charts, funding, OI, liquidations
- News firehoses and sentiment scores
- Generic LLM market Q&A
- Trade journals and Excel-like review
- Price alerts and simple watchlists
- Signal/copy products (explicitly outside NEXUS public boundary)

## Claims NEXUS cannot honestly call unique

- “AI that understands crypto” (commodity)
- “All-in-one market dashboard”
- “Faster news than Twitter/X”
- “Guaranteed alpha” or “beats the market”
- “Automated trading for everyone” (forbidden for public product)

## Decision Integrity combination opportunity

NEXUS wins by combining:

- structured **Decision Objects** (Context → Thesis → Evidence → Decision → Risk → Outcome → Review)
- dual human/AI **calibration**
- thesis invalidation monitoring
- Decision Time Machine / replay
- longitudinal Decision Graph
- evidence freshness and uncertainty display

Not by selling private Founder execution.

## Build versus integrate

| Capability | Decision |
|---|---|
| Market data / candles | Integrate (exchange + vendors) |
| News ingestion | Integrate + normalize |
| LLM reasoning | Integrate providers; own schemas |
| Decision Object model | Build (core IP surface) |
| Calibration / Outcome Review | Build |
| Thesis Integrity Monitor | Build |
| Publishing Gateway | Build (boundary critical) |
| Custody / order routing (public) | Do not build |

## Explicit reasons NEXUS could still fail

- Users treat it as another chat box and churn
- Decision Object friction exceeds research time saved
- Weak interview evidence for willingness to pay
- Over-claiming uniqueness vs terminals + ChatGPT
- Boundary leak that confuses public product with private trading core
- Regulatory misclassification if product drifts into advice/orders
- Concierge MVP fails retention before flywheel compounds
