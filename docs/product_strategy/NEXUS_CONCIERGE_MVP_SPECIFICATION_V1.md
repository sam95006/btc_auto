# NEXUS Concierge MVP Specification V1

Conceptual workflows only. No UI/API implementation in this track.

## First-stage workflows

**Today** → **Thesis** → **Decision** → **Monitor** → **Review**

AI Copilot is embedded inside these workflows. It is **not** a generic standalone chat page.

## Manual workflow

1. User captures Context Snapshot
2. Writes Thesis and invalidation
3. Attaches Evidence
4. Commits Decision (record only)
5. Monitors thesis alerts
6. Records Outcome and Review

## Automated workflow (assistive)

1. Copilot proposes evidence questions and challenge prompts
2. Thesis Integrity Monitor drafts alert candidates
3. Dual Calibration prompts appear at Review
4. User remains final decision-maker; no orders placed

## Six-to-eight-week test

- 10–20 ICP users (Concierge)
- Facilitated onboarding; weekly check-ins
- Measure closed Decision loops, not vanity DAU alone

## Success criteria

- Users complete multiple Decision → Outcome → Review loops
- Research time reported saved on repeated tasks
- Willingness to continue into second month (intent)
- No demand that public product must auto-trade

## Failure criteria

- Users only chat; never commit Decisions
- Alerts ignored; Reviews skipped
- Trust collapse from overconfident AI claims

## Kill criteria

- ICP cannot articulate paid value for Decision Integrity after 8 weeks
- Product usage collapses to generic news/chat substitute
- Boundary pressure to expose private trading core

## Pivot criteria

- Narrow to Thesis Integrity Monitor only
- Narrow to Decision Time Machine / replay for advisors
- Change ICP if interviews contradict launch ICP (with new evidence — not fabrication)
