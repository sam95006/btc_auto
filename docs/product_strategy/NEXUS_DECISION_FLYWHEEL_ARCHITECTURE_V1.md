# NEXUS Decision Flywheel Architecture V1

## Flywheel

Observe → Understand → Challenge → Decide → Record → Monitor → Review → Calibrate → Improve

Each stage strengthens the Decision Object and the Decision Graph.

## Core engines

### Decision Time Machine
Replay any Decision Object version with evidence freshness and AI/human traces.

### Dual Calibration Engine
Compare human and AI judgments against outcomes without collapsing loss into “bad process.”

### Thesis Integrity Monitor
Watch invalidation conditions and evidence drift; alert without auto-trading.

### Counterfactual Outcome Engine
Ask structured “what would have happened if invalidation fired earlier?” using user-recorded and public market marks — not private Founder fills.

### Private Intelligence Publishing Gateway
One-way sanitization boundary from Private Intelligence Core to Public Decision Cloud. Strips strategies, weights, orders, accounts, Lesson Memory, and exact entry/exit logic.

### Longitudinal Decision Graph
Graph of Decisions, theses, evidence, and reviews over time for retention and research efficiency.

## Non-goals

- Generic standalone chat home
- Signal marketplace
- Public automated execution
